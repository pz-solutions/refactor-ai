## Limits

The host verification ran on macOS. Windows drive/UNC simulation exercises production VFS code, but does not replace a native Windows run. The Windows CI job is prepared and must run after these changes are pushed; no live GitHub run was started here. That job covers TS/JS, copied skills and npm tools; C# on Windows and Windows ACL preservation are outside its current coverage.

Permission handling preserves POSIX access bits, not ACLs, ownership, timestamps or special mode bits. Compiler validation and initialization guards remain conservative checks; application tests are still needed for whole-program behavior, reflection and dynamic references. The existing documented concurrency and manual-recovery limits remain applicable.
